# Data Source Catalogue & Data Inventory (1.3 Lakh Records)

| Dataset Name | Record Count | File Formats | Description & Attributes |
| :--- | :--- | :--- | :--- |
| `ev_charging_stations` | 15,000 | CSV, Parquet | OpenStreetMap & OpenChargeMap schema (Lat, Lon, Operator, kW Power, Charger Type, Connectors, Status). |
| `vahan_ev_registrations` | 35,000 | CSV, Parquet | District & RTO-level Vahan EV registration numbers (2W, 3W, 4W, Bus, Total Regs, Growth Rate %). |
| `points_of_interest` | 60,000 | CSV, Parquet | Commercial & transport hubs (Malls, Tech Parks, Dhabas, Hotels, Fuel Stations) with footfall index & power availability. |
| `power_substations` | 10,000 | CSV, Parquet | Electrical substation grid nodes (11kV to 132kV, Spare Capacity in MW, Grid Reliability %). |
| `highway_corridors` | 10,000 | CSV, Parquet | National Highway corridor segment nodes (NH-48, NH-44, NH-65, NH-16, NH-66) with traffic volume & charger distances. |

**Total Dataset Scale**: 130,000 spatial records.
